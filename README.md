# ValutaTrade Hub - Платформа симуляции валютной торговли

Комплексное консольное приложение на Python для симуляции операций валютной торговли с управлением мультивалютными кошельками.

## Возможности

- **Управление пользователями**: Регистрация, вход/выход с безопасным хэшированием паролей
- **Мультивалютные кошельки**: Поддержка фиатных валют (USD, EUR, RUB) и криптовалют (BTC, ETH, SOL)
- **Торговые операции**: Покупка и продажа валют с курсами в реальном времени
- **Отслеживание портфеля**: Просмотр всех активов с конвертацией в базовую валюту
- **Обменные курсы**: Получение текущих курсов между любыми поддерживаемыми парами валют
- **Автообновление курсов**: Автоматическое обновление при истечении TTL кеша
- **Постоянное хранилище**: Сохранение данных в JSON для пользователей, портфелей и курсов
- **Логирование**: Полное логирование с ротацией для отладки и аудита

## Установка

1. **Клонируйте или скачайте проект**

2. **Установите зависимости с помощью Poetry**:
   ```bash
   make install
   ```
   Или вручную:
   ```bash
   poetry install
   ```

3. **Настройте API ключи** (опционально, для обновления курсов):

   Создайте файл `.env` в корне проекта:
   ```bash
   EXCHANGERATE_API_KEY=ваш_ключ_здесь
   ```

   Получить бесплатный ключ: https://www.exchangerate-api.com/

4. **Запустите приложение**:
   ```bash
   make project
   ```
   Или вручную:
   ```bash
   poetry run project
   ```

## Использование

### Доступные команды

- `register --username <имя> --password <пароль>` - Регистрация нового пользователя
- `login --username <имя> --password <пароль>` - Вход в аккаунт
- `logout` - Выход из текущей сессии
- `show-portfolio [--base <ВАЛЮТА>]` - Показать портфель (базовая валюта по умолчанию: USD)
- `buy --currency <КОД> --amount <число>` - Купить валюту
- `sell --currency <КОД> --amount <число>` - Продать валюту
- `get-rate --from <КОД> --to <КОД>` - Получить обменный курс
- `update-rates [--source <coingecko|exchangerate>]` - Обновить курсы валют
- `show-rates [--currency <КОД>]` - Показать все курсы
- `help` - Показать справку
- `exit` / `quit` - Выход из приложения

## Хранение данных

Данные хранятся в JSON файлах в директории `data/`:

- **users.json**: Учетные записи пользователей с хэшированными паролями
- **portfolios.json**: Портфели пользователей и балансы кошельков
- **rates.json**: Кеш обменных курсов с timestamps и источниками
- **exchange_rates.json**: История обменных курсов для анализа

## Конфигурация

Настройки загружаются в следующем порядке приоритета:

1. **pyproject.toml** - секция `[tool.valutatrade]`
2. **Значения по умолчанию** - встроенные в код

Пример секции в `pyproject.toml`:
```toml
[tool.valutatrade]
base_currency = "USD"
rates_cache_ttl = 3600  # TTL кеша курсов в секундах
decimal_places = 4
```

## Логирование

Логи записываются в `valutatrade.log` с автоматической ротацией (макс. 10MB, 5 резервных копий).

Уровни логирования:
- **INFO**: Основные операции (регистрация, вход, покупка/продажа)
- **WARNING**: Предупреждения (устаревший кеш, отсутствие курсов)
- **ERROR**: Ошибки (неудачные API запросы, ошибки валидации)

## Архитектура

Приложение следует слоистой архитектуре:

1. **CLI слой** (`cli/`): Обработка пользовательского ввода и вывода
2. **Слой бизнес-логики** (`core/usecases.py`): Реализация логики приложения
3. **Слой доменных моделей** (`core/models.py`): Основные бизнес-сущности
4. **Инфраструктурный слой** (`infra/`): Управление БД и конфигурацией
5. **Сервис парсинга** (`parser_service/`): Получение курсов из внешних API

Ключевые паттерны проектирования:
- **Singleton**: DatabaseManager, SettingsLoader (через `__new__`)
- **Decorator**: @log_action для логирования операций
- **Factory Method**: User.create_new() с хэшированием паролей
- **Abstract Base Class**: Currency → FiatCurrency, CryptoCurrency
- **Session Management**: TradingSession для состояния пользователя
